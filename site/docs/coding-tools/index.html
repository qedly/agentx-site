Connect after installation

You need an installed environment, project access, and the installed AgentX CLI. The public installation path is coming soon.

Register the MCP connection for your client:

agentx mcp install --client claude-code
agentx mcp install --client codex
agentx mcp install --client cursor

Choose the one command for your client. Reopen the client if it does not show the new server. Sign in when prompted. These commands configure a client connection; they do not deploy AgentX.

Delegate with complete instructions

List my available AgentX projects. In the export-service project, fix CSV exports that include empty records. Keep the column order, add a regression test, and report the diff and check evidence.

The client uses agentx_list_projects and agentx_start_task. The remote worker receives the task prompt, not your entire local conversation. Include all requirements it needs.

Expected result

A task ID, then status, progress, summary, changed files, artifacts, and PR links when available. Use agentx_get_task or agentx_wait_for_task to inspect it.

If waiting times out

A timed-out wait can leave the task running. Ask for its current status instead of submitting duplicate work. Cancelling a wait is different from cancelling the task.

Continue, share, and review

Use agentx_continue_task for a follow-up in the same workspace. Once the task ends, request agentx_open_pull_request for a draft PR, then inspect its URL with agentx_get_task.

Tasks are private unless shared or project policy requires sharing. agentx_share_task offers view mode or, when allowed, continue mode so channel members can steer it. Inspect the sharing destination and mode before asking to share.

When finished, agentx_close_task checks for unpublished work before releasing the workspace. agentx_cancel_task stops the current task; it is not closure.
