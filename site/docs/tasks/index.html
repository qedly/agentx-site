Before you start

Your admin has deployed the environment, registered the repository and project, and bound this Slack channel to that project. Installation instructions are coming soon.

01 / Request

Give a complete, bounded task.

Example request

@AgentX Fix CSV exports that include empty records. Add a regression test. Keep the existing column order. Report what changed and the commands that ran.

Use your workspace’s app mention. Say the expected behavior and constraints. Repository inspection and changes happen on the remote worker.

What you should see

A thread for this request with acknowledgement, workspace preparation, progress, and a result. First workspace preparation can take several minutes.

If it asks for confirmation

Inspect the proposed action. Approve runs that action; Cancel drops it. Confirmation depends on the project action policy and interpreted request.

02 / Inspect

Read the work and its evidence.

Inspect changed files, the agent’s account, and the runtime’s check report when available. Read failures and anything marked not verified before treating the task as ready.

How to interpret check evidence

If the result is incomplete

Ask a specific follow-up in the same thread. For a stopped or failed run, inspect the status and reported failure before starting another task.

03 / Continue

Refine it in the same thread.

@AgentX Also handle a file with only empty records. Keep the existing changes and rerun the relevant checks.

Continuing the same thread reuses its workspace and conversation context. Retained storage still costs money when compute is idle.

04 / Review

Ask for the pull request.

@AgentX Open a draft pull request for this change.

PR creation is an explicit action. Inspect its URL, diff, check evidence, and repository CI. A draft may contain failing checks; your team decides what gets merged.

05 / Finish

Close only after preserving the work.

@AgentX Close this workspace.

Closure checks for unpublished work. If it refuses, inspect the unfinished changes and preserve them before retrying. Stop, close, and cleanup.
