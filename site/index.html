06 / ABOUT AGENTX

AgentX itself is source-available.
Still private, with no public install.

AgentX is licensed FSL-1.1-ALv2. Each release becomes Apache 2.0 two years after it ships. The repository is private today; no public release or npm package is published. Until the release path is verified, the right first step is to understand the system and its prerequisites—not run a broken install command.
