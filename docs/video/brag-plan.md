# Brag plan: Rovara

Status: proposed production brief, not a rendered asset.

## Nine-question inspection
1. Coding agent in your AWS account, returning changes and usable check evidence for review.
2. Strongest line: Give it a task. Get the work back.
3. Hook: oversized black Anton typography, then the familiar Slack → AWS handoff on pale blue.
4. Use actual website typography, licensed vendor icons, exported journey diagram, and the example diff panel.
5. Twenty seconds lands the complete story without rushed reading.
6. Polished: confident, direct, tangible work. No parody, invented statistics, or fake customers.
7. Quiet instrumental bed and sparse warm UI accents, only after asset licensing is recorded. No voiceover.
8. Caption: Give it a task. Get the work back. Rovara runs a coding agent in your AWS account and brings back changes and check evidence for your review.
9. The source website is an explainer, not the running application. Animate the labelled task scenario; do not present it as captured Slack/AWS execution.

## Format and identity
Landscape 1920×1080; 20 seconds. Background #faf9f6; ink #10131a; accent #0754df; wash #eaf5ff. Anton display, Inter body, self-hosted fonts. Use the installed site's real assets. No customer names, real Slack IDs, internal URLs, or unverified pass counts.

## Storyboard
- 0–4s: “Give it a task.” A Slack icon and the example request “Fix the CSV export bug.” Land the request in a clean, readable composition. Small persistent “Illustrative workflow” label.
- 4–9s: “In your AWS account.” Request travels to the workspace portion of the actual journey diagram. Show AWS icon and “Remote coding agent.” Readability takes priority over beat synchronization.
- 9–15s: “Code to review. Evidence to inspect.” Use the example patch and text “Passed, failed, or not verified.” Do not animate invented green checks or raw output. Keep patch text large enough to read.
- 15–20s: A return path connects follow-up to the workspace. “Pick up where the task left off.” Then “You decide what gets merged.” Final Rovara mark and “Public release in preparation.”

## Audio
Sparse, quiet, professional; no narration. Select a licensed bed at composition time, preserve required attribution, and use at most three soft accents matching the visible handoffs. No waveform, strobe, or attention-grabbing pulsing. If the bed distracts from the task, choose intentional silence. Website playback remains user initiated.

## Acceptance
Every on-screen assertion exists in the current website and source claim references. Illustrative status remains legible. Four scenes total 20s. Hyperframes check and visual keyframe review precede render. Poster is a settled, readable work/evidence frame, never a blank transition. This video is an explanation, not live-product proof.
