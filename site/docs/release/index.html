Public source and published installer#

PrepLabsAI/Rovara is public. The npm package @preplabsai/rovara-code v0.3.1 (MIT) and v0.3.1 GitHub release were checked on 6 October 2026. Earlier v0.3.0 artifacts retain their Apache 2.0 terms and grant.

Install using Launch in AWS or the terminal →

Publication is separate from a fresh installation acceptance run. This website update checked release availability and documentation, and did not deploy a new AWS environment.

Product name and existing commands#

The public product repository is PrepLabsAI/Rovara; this website uses the approved display name Rovara Code. Package @preplabsai/rovara-code installs both rovara and the compatible agentx command. Configuration paths, AWS resources and MCP identifiers keep their existing identities.

Current licence#

PrepLabsAI grants the MIT License for all PrepLabsAI-owned Rovara code, including earlier releases. PrepLabsAI's previously issued Apache 2.0 grant also remains available for its owned code. Third-party components retain their own licenses.

Read the MIT License, the retained Apache License 2.0, and the license grant notice.

Runtime requirements#

The published CLI declares Node 22.19.0 or newer; Node 22 LTS is recommended. Launch in AWS does not need Node on your computer. The current install region is us-east-1.
