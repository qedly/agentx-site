Public installation is coming soon#

The public self-hosted installation guide is not available yet. These docs explain the currently inspected code and show how to work with an environment your team has already deployed.

Installation status →

Rovara and AgentX#

Rovara is the public-facing name used on this website. The current source project, CLI and integration tool names still use AgentX, agentx and agentx_…. Use those names in commands and existing app mentions.

Current licence#

The inspected product code uses FSL-1.1-ALv2. That is not an Apache-licensed open-source release at launch. The source licence grants a future Apache 2.0 licence effective on the second anniversary of the date the software is made available.

Read the complete current product licence for its terms. Website source and product source are separate repositories.

Runtime requirements#

The current AgentX package declares Node 22.19.0 or newer, below 23. Setup also depends on AWS, GitHub, Slack or a coding-tool connection, and configured model access. Installation instructions will specify the release-matched prerequisites.
