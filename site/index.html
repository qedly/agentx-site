How the work moves

One workspace holds the files and conversation. Follow up in the same thread instead of rebuilding the context.

01 / Request

Start where your team works.

Mention the installed bot in a project-bound Slack channel, or delegate from Claude Code, Codex or Cursor. You explicitly start the work.

First-task guide →

02 / Work

The agent works in your AWS.

A remote coding agent reads, edits and runs commands in a prepared workspace. Repository setup and model access come from your configuration.

Models and providers →

03 / Evidence

Inspect what actually ran.

04 / Review

Bring the work to a pull request.

Ask for a PR. Review its changes and check evidence alongside GitHub’s checks. Failing checks can remain visible in a draft PR. You decide what gets merged.
